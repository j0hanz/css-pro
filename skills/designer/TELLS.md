# Tells — execution-level defaults

Reference for **Critique the plan**, **Land the floor** steps, **De-slopping a built page** branch in [`SKILL.md`](SKILL.md). [`IDENTITY.md`](IDENTITY.md) names three default _looks_ plan falls into; this file names default _moves_ execution falls into. Same logic: **tell** = move appearing regardless of brief — made because model makes it on every similar page, not because page needs it. Uniqueness test at execution level: would exact move appear on similar but different brief? Yes = tell — replace with move specific to page, or delete (deletion usually right).

Motion tells not here — motion bar, flag list live in `motion-craft` (its REVIEW.md). Copy _method_ (voice, register, naming) lives in [`USABILITY.md`](USABILITY.md); copy family below is slop signatures, not method.

## Structure

- **Eyebrow on every section** — small uppercase wide-tracked label above each headline (`text-transform: uppercase; letter-spacing: .18em`) repeated per section produces same templated rhythm on every AI page. Headline alone almost always suffices; section's position on page already categorizes it. Budget eyebrows like **signature**: rare, earning their slot.
- **Section numbering as decoration** — `01 / INDEX`, `002 · Capabilities`, `01/4` on tiles. Numbering encodes info only when order carries meaning reader needs (SKILL.md structure rule); decoration numbering deleted.
- **Split-header floater** — big left headline, small explainer paragraph floating top-right aligned to nothing. Stack instead: headline, body under at readable measure. Split header only when right column carries real content (visual, interactive element), not filler text.
- **Same layout family repeated** — every section variation of image-beside-text, or third consecutive image/text alternation. Each section's layout derives from content's shape; page of many sections needs several distinct families.
- **Three equal cards** — reflex answer for any three things. Ask whether three actually equal; if one leads, lead with it.

## Ornament

Ornament tells share one replacement: delete, then confirm page still has **signature** — boldness spent on one memorable element, not sprinkled as decoration.

- **Decorative dots** — colored dot before nav items, list rows, badges. Dot earns its place only as live semantic state (server up, slot open).
- **Crosshair / hairline grid decoration** — rules drawn to feel "designed." Keep rules that organize real content; delete rest.
- **Scroll cues** — `↓ Scroll to explore`. Reader knows what scroll is.
- **Locale / weather / time strips** — `LIS 14:23 · 18°C` in nav or footer. Real contact address fine; atmospheric strip is costume.
- **Version stamps on marketing pages** — `v0.6` / `BETA` hero eyebrows, `Build 0048` footers. Keep only when brief literally is launch or preview announcement.
- **Pills and captions overlaid on images** — `PLATE · 03`, `Field study no. 12`. Image speaks alone, or one functional caption below it.
- **Hero-bottom text strip** — `DESIGN · BUILD · SHIP` mono-caps decoration. Keep only when it's real navigation or real status.

## Copy

- **Em-dash flourish** — em-dashes as rhythm device across headlines, labels, body. Model's signature punctuation; restructure into sentences, commas, colons.
- **Poetic section labels** — "Field notes", "From the bench", "Loose plates" over testimonials or blog rolls. Plain functional label ("Writing", "Testimonials") or none.
- **Mock-humble / micro-meta sentences** — "We respect the French ones." "The list will stay short on purpose." Cut; interface copy explains, never performs (USABILITY.md register rule).
- **Fake-precise numbers** — `4.1×`, `13.4 lb`, `92%` invented for spec-sheet aesthetics. Numbers come from brief's real content, or labeled mock.
- **Placeholder people and brands** — "Sarah Chan", "Acme", egg avatars. Brief's real content, or invented names living in subject's world (Ground step).
- **Filler verbs** — "Elevate", "Unleash", "Seamless". Concrete verbs describing what thing does.
- **Duplicate CTA intent** — "Get in touch" + "Let's talk" + "Start a project" on one page. One name per action, kept through whole flow (USABILITY.md).

Close family: read every visible string aloud in flow order; any string grammatically broken, referent-less, or reading as model performing thoughtfulness gets rewritten plain.

## Substance

Missing content faked structurally.

- **Div-built fake screenshots** — product "previews" assembled from styled rectangles, fake terminals, fake dashboards. Real screenshot, real embedded component, generated image, or no preview.
- **Gradient-blob hero** — text over blurred color blobs standing in for real visual. Hero is thesis (SKILL.md): open with most characteristic thing in subject's world.
- **Text-only "minimalism"** — page with no imagery reads as unfinished, not minimal. Restrained brief still gets 2–3 real images; none exist, leave labeled placeholder slots, say what's needed.
- **Plain-text logo walls** — brand names as styled spans in trust row. Real marks, or drop wall.

## Consistency locks

Positive rules; violating each is a tell.

- **One accent** — accent chosen in plan **tokens** used identically page-wide; second accent appearing in section 7 is drifted token, not choice.
- **One radius system** — radius steps from tokens (IDENTITY.md: two or three steps); mixed corners without stated rule read as assembly from different kits.
- **One theme** — page is light, dark, or auto; section flipping mode mid-scroll breaks page into two sites. Deliberate full-theme shift is signature spent once.
- **One copy register** — technical mono, editorial prose, marketing punch don't mix mid-page unless brief's voice says so.

## The check

Sweep rendered page (or diff) family by family: structure, ornament, copy, substance, locks. Each family either cleared or every firing tell named with replacement (or deletion) applied. Copy family includes read-aloud pass. Tell kept deliberately fine when it passes uniqueness test — say why brief needs it. Zero findings valid result; zero _checked_ families is not.
